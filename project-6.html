Web-based Online Store Application Project

Web-based online store application

FyzzCareer is a professional service website I built to offer portfolio sites, business landing pages, CV creation, and document formatting. It utilizes HTML, CSS, JavaScript, and Node.js (backend), alongside Bootstrap and various supporting JS libraries to enhance performance and aesthetics. The site features user accounts with login capabilities, order and direct consultation forms, an automated price calculator for cost estimation, dark and light modes for visual comfort, and real-time order status tracking. It is also installable as a Progressive Web App (PWA) for a native-like user experience. To boost engagement, I integrated a gamified mini-game (FyzzGames) that rewards successful players with service discounts, as well as a testimonial section where clients can review the services they received. I handled the project end-to-end—from business workflow planning and interface design to backend development using Node.js to manage order data, user authentication, and overall system logic.
